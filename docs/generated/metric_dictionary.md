## How each metric is computed

### Average install days (`avg_install_days`)

Mean RECEIVED to CABLED days.

- Type: simple
- Built from: average of `install_hours / 24.0` in `rack_delivery`
- Canonical query: [avg_install_days.sql](examples/avg_install_days.sql)

### Average vendor lead days (`avg_vendor_lead_days`)

Mean ORDERED to SHIPPED days.

- Type: simple
- Built from: average of `vendor_lead_hours / 24.0` in `rack_delivery`
- Canonical query: [avg_vendor_lead_days.sql](examples/avg_vendor_lead_days.sql)

### Burn-in regression rate (`burn_in_regression_rate`)

Share of completed racks with at least one status regression (the simulator only produces BURN_IN to CABLED regressions, so in practice this is burn-in failures).

- Type: ratio
- Built from: `racks_with_regression` / `racks_to_production`
- Canonical query: [burn_in_regression_rate.sql](examples/burn_in_regression_rate.sql)

### On-time delivery rate (`on_time_delivery_rate`)

Share of completed racks reaching production by their SLA due date.

- Type: ratio
- Built from: `racks_on_time` / `racks_to_production`
- Canonical query: [on_time_delivery_rate.sql](examples/on_time_delivery_rate.sql)

### Overdue open racks (`overdue_open_racks`)

In-flight racks past their SLA due date.

- Type: simple
- Built from: sum of `case when is_overdue_open then 1 else 0 end` in `rack_delivery`
- Canonical query: [overdue_open_racks.sql](examples/overdue_open_racks.sql)

### Median end-to-end days (`p50_end_to_end_days`)

Median order-to-production days.

- Type: simple
- Built from: percentile 0.5 of `end_to_end_hours / 24.0` in `rack_delivery`
- Canonical query: [p50_end_to_end_days.sql](examples/p50_end_to_end_days.sql)

### p90 end-to-end days (`p90_end_to_end_days`)

90th percentile order-to-production days.

- Type: simple
- Built from: percentile 0.9 of `end_to_end_hours / 24.0` in `rack_delivery`
- Canonical query: [p90_end_to_end_days.sql](examples/p90_end_to_end_days.sql)

### Racks in flight (`racks_in_flight`)

Racks ordered and not yet in production (point in time).

- Type: simple
- Built from: sum of `case when production_at is null and decommissioned_at is null then 1 else 0 end` in `rack_delivery`
- Canonical query: [racks_in_flight.sql](examples/racks_in_flight.sql)

### Racks on time (`racks_on_time`)

Completed racks with production_at <= sla_due_at.

- Type: simple
- Built from: sum of `case when production_at is not null and not is_sla_breached then 1 else 0 end` in `rack_delivery`
- Canonical query: [racks_on_time.sql](examples/racks_on_time.sql)

### Racks ordered (`racks_ordered`)

Racks with an order placed.

- Type: simple
- Built from: count of `rack_id` in `rack_delivery`
- Canonical query: [racks_ordered.sql](examples/racks_ordered.sql)

### Racks to production (`racks_to_production`)

Racks reaching production.

- Type: simple
- Built from: sum of `case when production_at is not null then 1 else 0 end` in `rack_delivery`
- Canonical query: [racks_to_production.sql](examples/racks_to_production.sql)

### SLA breaches (`sla_breach_count`)

Completed racks that missed SLA.

- Type: simple
- Built from: sum of `case when production_at is not null and is_sla_breached then 1 else 0 end` in `rack_delivery`
- Canonical query: [sla_breach_count.sql](examples/sla_breach_count.sql)

### Racks with a regression (`racks_with_regression`)

Completed racks with at least one status regression.

- Type: simple
- Built from: sum of `case when production_at is not null and regression_count > 0 then 1 else 0 end` in `rack_delivery`
- Component of `burn_in_regression_rate` (a ratio metric can only reference metrics); not reported on its own.

## Dimensions

Every metric can be grouped or filtered by:

- `metric_time`
- `rack__current_status`
- `rack_type__rack_type_code`
- `rack_type__description`
- `rack_type__is_gpu`
- `site__site_code`
- `site__site_name`
- `site__site_region`
- `vendor__vendor_code`
- `vendor__vendor_name`
- `vendor__contract_tier`
- `vendor__sla_days_order_to_production`

`metric_time` is each metric's time anchor (for example `production_at` for `on_time_delivery_rate`). `racks_in_flight` and `overdue_open_racks` describe the current state; grouping them by `metric_time` splits them by order date.
